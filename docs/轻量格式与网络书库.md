# 轻量格式与网络书库 · 0.3.14

以现有 ZIP、XML、HTML 解析和 Tauri HTTP 组件扩展；不打包“书转”的字体库、转换平台或完整渲染引擎。网络库代码按需加载，藏书按需下载。下载的书籍占用户数据空间，不计入安装包。

## 本次实现及边界

| 能力 | 本次实现 | 限制 |
| --- | --- | --- |
| OFD | 提取文字、页模板、PNG/JPEG 图片；按原页建章节；横竖排顺序、字距和文字对象变换 | 可重排阅读，不是 OFD 原版式渲染；不支持签章、矢量图、JBIG2、OCR、复杂组合变换 |
| HTML / HTM / XHTML | 本地文档与导出的文档，按 H1/H2 分章，保留安全的结构 | 去除脚本、交互控件、远程图片、网页样式；不处理登录页面 |
| ODT | 文字、标题、基本段落、内嵌 PNG/JPEG、标题作者 | 不完整复刻复杂办公排版 |
| PDF 文字重排 | 阅读菜单「文字重排」，选择页码生成独立文字书；按原页保留章节 | 原 PDF 和笔记保留，副本笔记独立；遵守复制限制；双栏、表格、脚注、竖排顺序尽力提取；无 OCR、图片和原版式 |
| Markdown | H1、H2 与下划线式标题进入分级目录，正文保留标题，忽略代码块内的伪标题 | 旧书根据已有章节 HTML 补充二级目录，不改书籍结构和笔记偏移；旧版已丢弃的正文一级标题不强行插回 |
| OPDS 1 / 2 | Atom/JSON 目录、分馆导航、下一页、当前页筛选、文件入架、收藏地址 | 暂无 OpenSearch 模板、租借/购买/DRM 解锁；Calibre 等需启用 OPDS 并提供 HTTPS 入口 |
| WebDAV | Depth 1 浏览文件夹、下载已有格式、收藏地址；适用于提供该协议的网盘/自建库 | HTTPS；Basic 账号与应用密码只保留在当前面板内；不是网盘厂商原生账号登录 |
| Legado JSON | 导入本地 JSON；搜索、解析目录、按章下载，作者及章节保留，下载后离线阅读 | 仅纯 CSS 规则子集；不执行任何 JS、不内嵌完整 Legado 引擎；不预装第三方书源 |
| 文件直链 | HTTPS 下载入架、进度、取消、超时和大小限制 | 每次 64 MB；没有 Content-Length 仍检查流实际大小；更大文件请本地导入 |
| 网页书单 / 飞书 | 提取公开静态页面里的 HTTPS 下载链接；飞书也可导出 DOCX/PDF/HTML 后导入 | 不执行远程页面脚本，不自动登录；飞书动态附件、知识库同步、网盘提取码暂不支持；单页最多展示 500 个链接并提示 |
| GitHub 公开仓库 | 输入仓库主页，浏览子目录，下载支持的书籍文件 | 未登录 API 有频率限制，单目录最多 1000 项；跳过大于 64 MB 的文件；不支持私有仓库、LFS 指针、JSON 诗词库自动转换 |

扫描 OFD 没有文字层时只能展示支持的位图，无法对图片内文字划线。需要保持版框、印章、复杂版式的 OFD 建议先转 PDF。压缩文档单项解压上限 40 MiB、合计上限 160 MiB，跳过嵌入字体，不将大型字体打入应用。

## 使用

书架打开「网络书库」：

1. **我的书库**：可直接选择古腾堡热门、中文藏书或搜索；展开「更多书库」查看其他入口。自定义时选择 OPDS、WebDAV、网页书单或 GitHub，填 HTTPS 地址。需要账号时展开「名称与访问账号」，填账号和应用密码，然后打开。点书籍的「入架」下载；点目录进入。收藏保存地址和名称，不保存密码；GitHub 不使用该账号密码。
2. **阅读书源**：导入已有 Legado JSON，兼容与不兼容的书源分别计数，失败会显示具体规则原因。选择源后搜索书名/作者，点「看目录」，选择起始章节和章数下载。默认 20 章，每批最多 100 章；可继续下载下一批。部分批次失败或取消时不创建半本书。
3. **链接导入**：填写真实下载地址。链接中没有扩展名时可填写「书名.epub」等文件名。返回登录或分享 HTML 页面时会提示先导出或获取直链。

局域网的 `http://192.168.…` Calibre 地址暂不接入，需要配置带有效证书的 HTTPS 入口。安装版复用原生 HTTP，不受网页 CORS 限制；浏览器开发版仍需要书库允许跨域。

## PDF 文字重排的使用

打开文字版 PDF → 阅读菜单「文字重排」→ 选择页码（每次最多 1000 页）→「生成重排副本」→「阅读重排副本」。副本可使用普通阅读器的字号、横竖排和划线。原 PDF 的书签、笔记和位置不迁移到副本，也不会被删除。全扫描或无有效文字映射的范围会提示无法提取，不生成空书；提取中可取消。

## Legado 规则子集

支持普通 CSS 选择器、可选 `@css:` 前缀、简单 `class.xxx` / `id.xxx` / `tag.xxx` 简写，以及 `@text`、`@html`、`@href`、`@src`、`@title`、`@content` 提取。空选择器加 `@text` / `@href` 表示当前列表元素。搜索地址支持 `{{key}}`（URL 编码）与 `{{page}}`。

```json
{
  "bookSourceName": "我的文本书库",
  "bookSourceUrl": "https://example.com",
  "searchUrl": "/search?q={{key}}&page={{page}}",
  "ruleSearch": {
    "bookList": ".book",
    "name": "a@text",
    "bookUrl": "a@href",
    "author": ".author@text"
  },
  "ruleToc": {
    "chapterList": ".toc a",
    "chapterName": "@text",
    "chapterUrl": "@href"
  },
  "ruleContent": { "content": "#content@html" }
}
```

以上只是规则示例，`example.com` 不是预置书源。可选 `ruleBookInfo.tocUrl` 支持从书籍详情页取得目录地址。不支持 JS、JSONPath、XPath、正则替换、组合规则、目录/正文多页合并、逆序/分卷特殊规则、POST、自定义请求头、登录和 WebView 验证。第三方网站改版或限制访问也可能导致已有规则失效；“JSON 导入成功”并不保证网站在线可用。

## 电脑版关闭与退出

点窗口 × 或 Alt+F4 收到系统托盘，阅读位置保留。单击托盘图标可恢复窗口；右键选择「退出阅读树」才结束程序。书架底部也提供「退出阅读树」。若系统不支持托盘，则关闭操作退化为最小化到任务栏，避免窗口无法找回。Android 返回行为保持上一版的返回书架、书架连续两次返回退出。

## 暂不做的较重集成

完整 OFD 版式引擎、OCR 模型、大型中文字体库、独立浏览器运行时、完整 Legado 脚本运行环境不进入本次安装包。飞书和各家网盘的完整 OAuth/接口接入主要增加维护与授权复杂度，不一定明显增加体积，但不适合作为无账户配置的通用轻量入口；本版明确以文件与协议方式接入。

## 验证

`node scripts/test-network-formats.mjs` 覆盖独立 OFD 模板/CTM/字距/竖排样本、XML 实体拒绝、ODT、HTML 清理、Markdown 标题与旧书定位、OPDS 1/2、WebDAV、书源下载入架、网络限制与密码隔离。若参考项目样本仍在本机，也会读取它的横排、竖排、半叶 OFD。在线服务通过受控响应验证，不代表所有第三方书源和真实账户都已测试。

`node scripts/test-public-libraries.mjs` 覆盖公共入口、网页链接过滤、GitHub 目录/限流/LFS、国学汉籍章节范围下载与取消、PDF 真实文字层重排、页码/复制限制/扫描页提示，以及原文件与书签保留、手机面板和返回行为。`node scripts/test-desktop-lifecycle.mjs --libraries` 在独立 Windows 生产书库中验证原生网络实际访问及下载，然后验证托盘关闭、恢复和退出。
