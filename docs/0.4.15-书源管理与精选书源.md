# 0.4.15 书源管理与精选书源

本次保持 0.4.15 版本重打包：阅读书源页只保留首句导入说明，依次展示文件导入、精选书源、精选公共书库及检测工具。新增“一键清空所有书源”，确认后清空配置，保留已入架书籍。

检测结果逐条保存至本地，关闭面板或退出应用后重新打开可恢复；中途中止可点击“继续检测剩余”。结果按完整书源配置匹配，规则变更后需要重测，移除书源不会使其他源的结果错位。更换检测书名后重新检测；“检测全部书源”用于主动复检。

Downloads 的书源另行实测、导出，未加入内置精选源，也未导入用户书库。单独文件及检测记录位于 Downloads/阅读树_可用书源_20261128。

打开“网络书库”，顶部直接点击“书源管理 · 检测/清理”。标题显示 v0.4.15，批量检测区域默认展开，不再隐藏在折叠区。此前 0.4.14 同版本重打包无法仅凭版本号辨别新旧，本次提高版本号和安卓版本代码；无需卸载、清除书库。

## 一键添加可用书源

点击“一键添加 3 个精选书源”，自动保存规则，默认选择 5000言并填入“西游记”；点击“搜索书源”，选择结果查看目录，再下载章节入架。重复添加会合并更新，不会无限增加重复源。

| 书源 | 实测书名 | 目录章数 | 首章结果 |
| --- | --- | --- | --- |
| 5000言 · 经典名著 | 西游记 | 100 | 含“混沌未分天地乱” |
| 5000言 · 经典名著 | 论语 | 512 | 含“学而时习之” |
| 5000言 · 经典名著 | 道德经 | 81 | 含“道可道” |
| 国学汉籍 · 热门文字古籍 | 史记 → 三家注史记 | 138 | 读取史记索隐序 |
| 落霞读书 · 古典小说 | 西游记、红楼梦 | 以实时目录为准 | 使用应用同一读取引擎验证 |

这三条规则按站点公开目录筛选书名，范围分别为首页经典名著、热门文字古籍和古典小说分类，不是全站无限搜索，不保证任意网文能找到。文件中的 `ruleSearch.filter: "title"` 是阅读树 0.4.15 新增的目录检索约定：先加载公开目录，再按标题匹配；旧版不能正确使用这个筛选约定。

独立文件“阅读树_精选书源.json”可从“导入书源 JSON / TXT”导入，内置按钮使用同一份规则。没有认证请求、不执行网站或书源 JavaScript。站点后续改版、网络差异仍可能影响使用。

## 批量清理

输入适合你的书源的检测书名，点击“检测全部书源”。实测搜索、目录、首章正文，不入架；可随时取消。失败和无结果分开显示，选择后点击“批量移除所选”，确认数量后删除配置。已入架书籍保留。无结果可能只是该书源没有所测书籍，建议换书名复检。

## 验证边界

2026-11-28 使用电脑真实网络，应用原有解析、目录和正文下载引擎完成样本测试；浏览器测试通过 Node 网络转发实际站点响应以避免开发环境 CORS，不伪造站点内容。手机地区、系统代理和站点限制可能不同。本轮尚未用安卓真机确认覆盖安装后的页面。
