# 网络书库扫码与 HTTP

Android 的“我的书库 → 扫码添加书库”可调用相机扫描 Olib / OPDS 二维码；首次使用需授予相机权限。也可选“识别二维码图片”，从相册或电脑选择图片。

识别后先核对书库类型、地址，再点“打开书库”浏览，选择书籍入架。二维码不会自动下载或保存密码。Olib 无线分享的根地址转换为同服务器的 `/opds` 入口；已有 OPDS 路径和查询参数保留。其他服务若根路径并非 OPDS，请手动修改地址。

OPDS、WebDAV、网页书单和文件直链支持 HTTP / HTTPS。HTTPS 跳转降为 HTTP 仍会停止；跨域跳转不会转发账号密码。网页版仍受浏览器的跨域和混合内容策略限制。

阅读书源支持 `.json`、`.txt` 文件，支持 BOM、UTF-8、UTF-16、GB 等文本编码。TXT 内容应为阅读 / Legado 的 JSON 书源规则，并非网址清单。仍只支持既有的纯 CSS 规则，不执行脚本。

0.4.12 起，单个导入文件上限为 50 MiB（界面显示 50 MB），单次导入和累计保存最多 100000 个书源。按书源名称和地址识别重复项并更新，容量已满时仍可更新已有书源。选择列表支持名称 / 地址筛选，每页最多显示 100 个；只请求当前选中的一个书源。大文件读取与 JSON 解码仍需占用内存，实际速度取决于设备；规则校验和合并分批执行并支持取消。

电脑书库需监听局域网 IP 或 `0.0.0.0`。若 Windows 防火墙拦截访问，应允许书库程序接收局域网连接，或仅放行其 TCP 服务端口；一般配置一次，端口或网络策略改变时需再检查。无需关闭整个防火墙，阅读树也不会自动修改其他电脑的设置。

扫码组件：jsQR（Apache-2.0）、ZXing Android Embedded 4.3.0（Apache-2.0）及其 ZXing Core 依赖（Apache-2.0）。上游：https://github.com/cozmo/jsQR 、https://github.com/journeyapps/zxing-android-embedded 、https://github.com/zxing/zxing 。
