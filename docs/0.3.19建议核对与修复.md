# 0.3.19 建议核对与修复

本次核对用户提供的新审查报告，优先处理已经证实的阅读缺陷、数据保护与小体积改进。

## 本次实现

- Web TTS 暂停会失效旧回调，恢复重新朗读当前句；迟到的旧回调不会推进队列。
- PDF 独立入口，避免普通阅读器同时运行计时、进度和键盘监听；PDF 自己加载批注。
- PDF 文本层使用 CSS 像素的 viewport 和 --scale-factor，匹配高分屏画布；取消旧 TextLayer/Canvas 任务并检查异步存活状态；批注变化只更新标记。
- PDF 滑动后阻止随后合成点击；菜单收起层避免被 PDF 文本层挡住，也不再冒泡重新打开。
- 普通正文和 PDF 增加复制。兼容剪贴板权限失败时的旧 WebView 复制，并保留选区。
- PageUp/PageDown/空格翻页，Shift+空格上一页；Escape 关闭笔记编辑卡；输入框保持正常输入。
- 备份无条件排除 sync-* 和 device-id；恢复旧包不导入其中的凭据，完整恢复时保留本机 sync-config/device-id，重新建立同步状态。
- 打开菜单采用视觉缩放正文预览，不改变分页器布局；笔记定位将矩形换算回原始坐标，避免缩放导致跳错页。
- 选区颜色和操作按钮至少 44px；按钮增加按压反馈；笔记字体和边框使用现有主题变量。
- 网络下载按收到数据重置 60 秒计时，连续无数据才超时；用户取消与体积限制继续生效。
- EPUB、FB2.ZIP、CBZ 解压前检查每项声明大小、总量和条目数：总量 512 MiB、单项 128 MiB、最多 30000 项。该限制不代表大文件导入已完全移出主线程。
- 滚动进度按 requestAnimationFrame 合并更新，不再每个事件都设置状态；章节扫描到当前可视位置后停止。
- 设置写入串行化，失败显示提示和重试；删除正在全局使用的字体时持久保存宋体回退。
- ZIP 的 accept 用于 FB2.ZIP，并非完全没有 ZIP 分支；普通 ZIP 与 RAR/7z 给明确转换提示。

## 已有能力，未重复开发

持久存储请求、用量展示、回收站、跨书搜索、同步批量读取、未变化正文跳过、CI、Vitest 与版本发布工具已在 0.3.18 实现。同步删书和墓碑已经在同一事务提交。

## 仍值得后续开发

EPUB 跨章节脚注/内部链接、解析 Worker、同步 manifest ETag 与并发合并、冲突副本、自动滚动备份、文件关联/分享导入、锁屏朗读、全壳主题、漫画懒加载和统计扩展仍待实现。它们涉及数据协议、原生生命周期或大幅结构改动，本次未宣称完成。

不在未经验证的情况下打包大字库、字典、音频引擎或漫画解压器。同步密码仍按用户要求默认记住，本次只阻止它进入备份包。

## 验证

新增隔离浏览器专项验证涵盖 TTS 暂停恢复与旧回调、完整备份不含连接凭据、PDF 双倍 DPI 文字位置、批注不重绘画布、计时仅一次、PageDown、菜单标题留白、复制后选区保留。新增压缩包限制和设置失败/字体回退单测。

28 项单元测试与 130 项原有阅读/面板/触屏回归通过；跨书搜索/回收站和本次专项浏览器验证通过。另覆盖超过一分钟的有进度慢下载、停滞下载超时、主动取消，以及旧备份凭据隔离和损坏备份不写入。

0.3.19 Windows 安装版、安卓签名 APK、源码 ZIP 已生成。Windows 与安卓两个 ABI 内嵌前端、样式和书库资源逐字节核验通过；APK 图标及 v2 签名验证通过。安卓实机触控、真实语音引擎与多设备云端并发仍需实机验收。
