# 0.4.7 WebDAV 书库修复

## 原因

同步设置已支持 HTTP，但“网络书库”的地址校验、目录链接解析和下载请求仍限定 HTTPS，因此本地代理及局域网 WebDAV 被阻止。安卓系统网络备用通道也有单独的 HTTPS 限制。

## 使用

1. 覆盖安装 0.4.7，打开“网络书库 → 我的书库”。
2. 书库类型选择“WebDAV 文件夹”，填写云盘提供的 HTTP 或 HTTPS 文件夹地址。
3. 展开“名称与访问账号”，填写账号及密码，点击“打开书库”。
4. 点击文件夹逐层浏览，点击书籍“入架”即可下载到本地书架，之后可以离线阅读。

电脑访问本机运行的服务可以用 `127.0.0.1`。手机访问电脑服务需要电脑的局域网 IP，并确保同一网络、服务允许局域网访问、端口未被防火墙阻止。手机的 `127.0.0.1` 指手机自身。

HTTP 连接不加密账号和内容，仅应在可信网络使用。收藏只保存名称、地址及类型，不保存密码。服务器跳转至其他站点不会携带书库账号密码；HTTPS 降级到 HTTP 的跳转会被拒绝。

## 验证

- `node scripts/test-webdav-library.mjs`：真实本地 HTTP WebDAV 服务，验证认证、子目录、中文文件名、下载入架、返回、收藏、跨站认证隔离、HTTPS 降级阻止、安卓桥接分流及手机/桌面宽度。
- `npm run typecheck`、`npm run test:unit`。
- `node scripts/test-network-formats.mjs`、`node scripts/test-android-network.mjs`、`node scripts/test-app-update.mjs`。
- 打包后运行 `node scripts/verify-release-assets.mjs`，确保电脑与安卓包实际包含新前端和安卓 HTTP WebDAV 桥接。

上述网络测试使用独立的临时服务和测试账号，不连接个人云盘。真实个人云盘的可达性、权限及代理上游状态仍需在实际使用设备上确认。
