# 0.4.16 备份容量与分批记录

每批最多 200 本，累计原始数据上限为 256 MiB（268435456 字节），导入入口允许最多 260 MiB 的 ZIP，以容纳压缩包目录等开销；解压后仍检查 256 MiB 上限。旧备份继续兼容。

导出后需点击“文件已保存，记录本批”才写入本机持久记录；“未保存，不记录”不改变记录。默认跳过已确认备份书籍，重新打开面板或应用后仍有效。完整备份记录可用于跳过轻量备份，轻量记录不能跳过完整备份。

记录只表示书籍曾经备份，不判断后续正文、进度、笔记变化，也不验证备份文件是否仍存在。需要最新快照时取消“跳过本机已确认备份的书籍”。旧版导出没有记录，无法自动追溯。本机记录不随备份迁移，清除应用数据会清除记录。

发布目录为 `releases/0.4.16 256MiB备份与分批记录/`，包含 Windows 安装包、安卓双架构签名 APK、源码、发布说明、更新清单和 SHA256 校验。后续发版先使用 `version:set` 升级版本，再更新 `package.json` 的 `releaseDescription` 和 CHANGELOG，运行 `release all`。

验证：现有 81 项单元测试、2 项容量回归、38 项大书库检查及备份界面流程通过；65 MiB 原始文件恢复后字节长度和尾字节正确。界面覆盖未保存不记账、确认保存、重启后跳过、轻量/完整区别和手动重复导出。
