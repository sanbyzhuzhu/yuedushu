# 发布与许可证

## 版本与验证

使用 `node scripts/set-version.mjs 0.3.18` 明确设置版本；该命令同步 npm、锁文件、Cargo 和 Tauri 配置。普通构建不自动升版。更新 CHANGELOG.md 后运行版本检查、类型检查、单元测试、生产构建和冒烟回归。

`node scripts/generate-notices.mjs` 从已安装的生产依赖生成 THIRD-PARTY-NOTICES.md，包含包名、版本、许可证和包内许可声明。升级依赖后需重新生成。原生 Rust 依赖仍须另行审查 Cargo.lock 对应许可证；此生成器不声称覆盖原生依赖、系统 TTS、用户字体或外部书库内容。

## 签名

Android 发布包使用现有发布证书，升级时不得重新生成证书。通过环境变量 TAURI_ANDROID_KEYSTORE_PATH、TAURI_ANDROID_KEYSTORE_PASSWORD、TAURI_ANDROID_KEY_ALIAS 注入；本机可使用被忽略的 .android-signing.local.json，禁止上传、打入源码包或输出到日志。持续集成构建时通过仓库 Secrets 写入临时证书并注入上述变量，结束后删除临时证书。

Windows 当前安装包未配置受信任的代码签名，系统可能显示未知发布者。正式公开发布可配置可信代码签名服务；不得把证书或私钥提交到仓库。用户应核对官方分发文件与 SHA256SUMS.txt。

## 产物

release.mjs 保存安装包、安卓包和源码压缩包，并生成 SHA256SUMS.txt。源码包排除签名资料、依赖缓存和构建产物。当前源码与历史安装包不能视为同一版本实现；须重新构建后用 verify-release-assets.mjs 验证内嵌前端资源。

网络书库内容与字体各有自己的许可，链接接入不代表可以再次分发；软件不捆绑大型字库或电子书数据集。
