# 0.4.13 诗词与公开仓库 JSON

在“网络书库 → 更多书库 → 中华诗词”中浏览 `chinese-poetry/chinese-poetry`，或者选择“GitHub 公开仓库”填写公开仓库主页。

进入文件夹后，JSON 条目支持以下操作：

- 点“预览 JSON”，按题目、作者或正文筛选，勾选所需篇目，填写选集名称后点“所选诗词合并入架”。每页展示 50 篇，选择可跨页保留。
- 点“整份 JSON 合并入架”，将文件中所有可读篇目整理成一本书。
- 在目录中勾选多个 JSON 文件，填写“合并书名”，点“合并所选 JSON 入架”。同一文件夹内的选择可跨筛选保留，切换目录后清空。
- 点“保存 JSON”或预览页的“下载原始 JSON”，保存整个原文件。保留原始编码、BOM、空白和字段；不重新序列化，也不执行数据中的内容。

支持常见诗词数组，或 `poems`、`chapters`、`data` 数组包装。正文可使用 `paragraphs`、`content`、`contents` 字符串或字符串数组；题目支持 `title`、`rhythmic`、`chapter`、`section`、`name`，保留 `author`。缺少正文或结构不匹配的条目显示为非诗词数据，不合成空白章节；原始文件仍可保存。

单个 JSON 最大 50 MiB；预览最多 100000 条记录，每本合并选集最多 10000 篇、正文最多 256 MiB。超过合并数量时可分批入架，也可保存原始 JSON。选择多个文件合并时，共计不能超过 10000 篇。

本功能处理公开诗词数据文件，不等于支持所有 JSON 数据库，也不改变阅读 / Legado 搜索书源的现有兼容范围。私有仓库、登录、验证码和脚本型书源需分别适配。GitHub API 的访问频率、网络可达性与网站改版仍影响在线访问。
