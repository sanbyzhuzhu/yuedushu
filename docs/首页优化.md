# 0.3.14 清简书架版

应用版本仍为 0.3.14，安卓版本代码仍为 3014。在首页点右上角「⋯ → 关于阅读树」，应显示「v0.3.14 · 清简书架版」。版本说明移入关于，不再占用书架空间。

## 首页布局

- 顶部保留加书、更多与搜索；有阅读进度时，搜索下方直接显示续读。
- 手机分类横向滑动，右侧固定「全部分类」。可按名称查找分类，选中后横栏自动展示当前分类；同名子分类在分类面板显示父分类。
- 阅读状态、排列、管理合并为一行。「排列」调整排序与网格/列表/树架，偏好继续保存在本机；「管理」进入分类管理或批量整理。
- 「更多」内放网络书库、阅读统计、备份/恢复、坚果云同步、关于；Windows 的明确退出入口也在这里。关闭 Windows 窗口继续收至托盘。
- 顶部仅显示简洁页码，点击展开跳转输入；底部保留上一页/下一页，翻页后回到书架顶部。安卓返回键、Escape 和点外部都可收起页码输入。
- 空书架只突出「导入第一本书」和「网络找书」，另保留示例古籍；筛选、排序、页码和批量整理在有书后显示。
- 电脑保留分类侧栏，分类列表独立滚动，分类管理与网络书库入口留在底部。

## 视觉与体积

保留米白纸色、细分隔线、朱砂小印和古籍封面。操作文字使用系统字体提高辨识度，标题与书名延续宋体风格；不打包额外字体、图像或运行时依赖。

390 × 844 手机尺寸视口，包含续读、30 个分类及多页书籍时，第一排封面位于约 352 像素；上一版大书库截图约为 612 像素。此项是浏览器布局测量，不是安卓性能测量。

## 验证

本轮 25 项首页检查、31 项面板检查、24 项书架/书签检查、38 项万本书库检查、40 项网络/格式检查、37 项公共书库/PDF 检查，合计 195 项；另进行 TypeScript、生产页面跨页划线保存恢复和安装包资源核验。

覆盖 320、390、768、1280 像素宽度，检查空书架、分类搜索、视图切换、页码跳转、批量归类、菜单入口、安卓返回回调及键盘焦点。未连接安卓真机；本轮没有重测全部第三方网站的实时可用性。

万本容量、分批备份及格式支持延续之前版本，详见 [大书库优化](大书库优化.md) 和 [轻量格式与网络书库](轻量格式与网络书库.md)。
