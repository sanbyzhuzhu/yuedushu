# 0.4.9 入架即时刷新

## 原因

1. 导入已经提交到数据库，但原来的分类、关键词、读完/在读筛选及书架页码仍在，新书不在当前结果或当前页。
2. 较早启动的书库读取在新书入架后返回，会把旧快照写回界面状态；数据库中有书，重启重新读取才显示。
3. 批量导入原来攒到 20 本或整批结束才发布书架状态。下一本解析较慢时，前面已经保存的书也不会及时显示。

## 修复

- 各入架入口使用同一个发布通知，在数据持久化成功后更新书架，按 ID 去重。
- 书架收到通知后回到全部藏书、清空关键词和阅读状态筛选、定位第一页并优先展示刚加入的书。原排序方式和网格/列表/树架偏好不变。
- 阅读期间接收的书先保留定位通知，返回书架且偏好读取完成后再定位，避免旧偏好重新挡住新书。
- 批量导入立即发布首本，此后达到批次上限、时间间隔或结束时再发布，取消时仍保留已经提交的书。
- 书库读取使用请求代次，过期请求不再应用；有效请求返回时保留读取期间发生的新增、编辑和删除。
- 隐藏书籍仍遵守原有隐藏规则；此次修复不取消已有书籍的隐藏状态。

## 验证

`scripts/test-import-refresh.mjs` 覆盖旧搜索/分类/读完筛选与第二页入架、异步读取竞态、慢速批量导入首本、网络入架、书架与阅读期间拖入、读取期间删除。

`tests/librarySnapshot.test.ts` 覆盖快照合并、并发导入、编辑、删除、分类新增与去重。另回归封面、隐藏分组、书架管理、WebDAV、大书库及更新流程。

测试使用临时书库和测试文件，不连接个人云盘。安装包需覆盖安装新版本才能生效。
