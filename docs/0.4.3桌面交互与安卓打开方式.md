# 阅读树 0.4.3

## 电脑使用

- 从资源管理器拖入一本或多本电子书，松开后导入。书架、正在阅读时都可接收，显示进度和失败原因，不移动或删除原文件。
- 分页阅读及 PDF 中，滚轮向下翻下一页、向上翻上一页。触控板同一段惯性滚动只翻一页；停顿后继续滚动再翻页。
- 选中文字、按住鼠标拖选、打开菜单或弹层时不触发滚轮翻页。Ctrl + 滚轮保留系统缩放；滚动阅读保留自然滚动。
- 鼠标按住左键选字，拖到末行后继续往外拖可跨页，松开后显示划线菜单。

## 安卓使用

安装正式版 APK 后，在文件管理器选中 EPUB、TXT、PDF 等电子书，选择“打开方式 / 更多打开方式 → 阅读树”。也可使用“分享 → 阅读树”。单本导入后自动打开，多本分享依次导入。

支持软件尚未启动和已在运行两种情况。系统通过临时读取授权交付文件，不要求访问所有文件。若文件管理器已记住其他默认应用，需先选“其他应用打开”或清除该应用的默认打开设置；具体名称因系统而异。

支持格式与内部导入一致。外部文件单本上限 256 MiB，分块传输并在导入后清理临时文件；格式不受支持或读取失败会给出提示，其他文件继续导入。

## 打包

版本 0.4.3，沿用 `com.readingtree.app` 与原正式版签名。交付 Windows x64 安装程序、Android 双架构 release APK、当前工作内容源码 ZIP 和 SHA256SUMS.txt。

验证命令：`npm run typecheck`、`npm run test:unit`、`node scripts/test-external-input.mjs`、`node scripts/test-selection-mouse.mjs`、`node scripts/test-selection-touch.mjs`。原生包完成后再检查实际内嵌前端、安卓 intent-filter 与签名；没有连接安卓真机时，不将桥接模拟测试视为手机端到端验收。

## 本次验证结果

- TypeScript 检查、35 项单元测试、18 项外部输入检查、横竖排鼠标跨页测试、36 项触摸检查通过。
- `test-native-drop.mjs` 在隔离的实际 Windows WebView2 中验证原生拖入事件、读取文件、失败文件不阻断后续导入，以及真实滚轮翻页；窗口关闭收至托盘、托盘恢复、退出检查通过。
- Android 15 只读模拟器安装本次正式 APK；系统对 EPUB、TXT、PDF、通用二进制和 MOBI 列出阅读树。从实际文件管理器完成冷启动打开、运行中再次打开和分享导入，并在阅读页确认正文。模拟器测试脚本为 `node scripts/test-android-open.mjs emulator-5580`，仅用于可丢弃模拟器。没有连接实体手机。
- APK 为 0.4.3 / 4003，包含 arm64-v8a、armeabi-v7a，签名有效且与原 0.4.2 正式版证书一致。
- Windows 与 APK 两种架构内嵌的前端、样式、笔记及书库模块与最终生产构建逐字节一致；APK 中保留外部导入桥与 VIEW / SEND / SEND_MULTIPLE 注册。
