# 功能与古典极简设计审查

## 判断标准

极简是默认界面只呈现当前需要的操作；古典由纸色、墨色、字体、题签和留白共同体现。朱砂用于选中态和主要动作，正文优先，装饰按需开启。功能名称仍使用直白中文，避免为了古风增加理解成本。

此前已有宣纸色和竖排基础，但不同面板密度不一致，设置是很长的控制列表，列表书架常显编辑、分类和删除操作，部分说明带有过时版本号和实现术语。本轮针对这些问题统一整理。

## 逐项处理

| 功能 | 问题与优化 |
| --- | --- |
| 藏书网格 | 默认封面加入题签和书脊线；书名、作者或进度分层显示；整张书卡可用键盘打开。 |
| 列表书架 | 编辑、分类、删除收进更多菜单，默认只显示书籍信息；点击外部收起菜单。 |
| 续读与筛选 | 加入最近在读书籍的续读入口；保留视图、排序和筛选偏好，修复初始化时提前写入默认值的问题。 |
| 古树视图 | 补齐颜色图例、键盘操作和完整藏书索引；树上图形展示有数量限制时，仍可通过索引找到全部书。 |
| 导入 | 批量导入中个别文件失败会继续处理其他文件，最后列出失败文件；导入过程中提供状态。 |
| 书籍编辑 | 空书名直接提示；等待保存完成再关闭，失败保留输入。 |
| 阅读与 PDF | 统一菜单、划线工具与笔记面板；手机底部进度和操作分行，给主要按钮足够空间。PDF 划线样式跟随设置。 |
| 排版 | 分为常用、纸墨、版式、更多；加入舒朗、古籍、舒目三种阅读预设。修正本书独立设置无法切回全局的问题。 |
| 字体与导入样式 | 字体导入失败显示提示；原书样式开关明确为后续导入使用的全局设置，避免误以为能即时改变已导入书籍。 |
| 目录 | 增加章节序号和当前章节标记，长标题可换行。 |
| 全书搜索 | 缓存章节纯文本并延迟计算输入，结果可跳到匹配文字所在页，短暂标出原文；支持英文大小写不敏感查找。 |
| 笔记与导出 | 增加摘录/批注内容检索、类型筛选和所属章节；导出格式收进一个入口。 |
| 朗读 | 播放和语速优先显示，音色、定时、连播放入可展开的偏好设置。 |
| 阅读统计 | 修复“近 30 天”和“累计”只统计 14 天的问题；一次读取统计记录，累计覆盖全部历史；半年热力图按需展开。 |
| 云同步 | 未启用或未完成配置时禁止空操作；显示待首次同步状态；服务器、目录收起为连接设置；删除过期版本说明。 |
| 本地备份 | 用轻量/完整备份解释差异，明确 PDF 与自定义字体需要完整备份；区分导出与覆盖恢复，提供操作状态。 |
| 所有抽屉 | 统一纸色、字号、边框和按钮大小；支持 Escape、焦点回到原入口、Tab 保持在面板内；考虑窄屏和安全区。 |

## 验证入口

- `npm run typecheck`：类型检查。
- `npm run build`：生产构建。
- `npm run test:reader`：划线、分页、笔记和持久化回归。
- `npm run test:panels`：书架、设置、统计、同步、备份、树架、搜索和面板交互检查。使用独立测试书库，不连接真实云账户。
- `output/playwright/audit/`：主要面板在手机尺寸、桌面和夜间主题下的截图。

## 尚需真实环境验收

0.3.10 验证：63 项阅读回归、36 项触摸输入检查、31 项面板交互检查通过。横排、竖排和双页使用实际鼠标手柄拖动跨页并核对保存文字；触摸输入检查长按、跨两页、反向缩选、松手和取消。面板截图已核对手机宽度、桌面书架和夜间主题。主题预览保留各自配色，装饰色支持键盘选择。

- Android WebView 选字、软键盘和系统朗读声音需真机验证；浏览器触摸测试只能覆盖前端交互。
- 坚果云账户连接、流量与下载恢复需实际账户环境，本轮不代表完成云端端到端验收。
- 扫描型 PDF 若没有文本层仍不能直接选字；复杂 EPUB 的排版取决于源文件结构。
- 字体优先使用设备已有字体。不同系统的宋体、楷体字形可能有差异；自定义字体入口仍可使用。

当前方向已统一为古典极简。后续应优先依据真实阅读反馈调整触控与排版细节，避免再增加常显入口、装饰卡片或重复提示。

## 0.3.11：留白、图标与阅读细节

- 竖排有版框时，正文上下各留约 0.6 个字的空隙；界行仍接到版框，整列翻页与划线位置保持对齐。关闭版框即恢复原正文高度。
- 图标保留宣纸底、五色果实和书本，重新调整树冠与书页比例。Android 使用独立透明前景和纸色背景，主体全部位于 66/108 安全圆内；普通与圆形启动图标都提供自适应资源。
- 笔记在输入时自动保留本机草稿，关闭编辑或重新打开应用不会丢失；可以继续写、正式保存或放弃草稿。草稿与正式笔记区分，不参与导出、备份或同步。保存、删除和生成分享图分别显示对应状态。
- 目录增加章节名筛选，结果保留原编号并跳转到正确章节，无结果时给出简短提示。
- 新增 `npm run test:polish`：23 项检查覆盖手机横竖屏、18/24/32 字号、首屏/后续页留白、框线开关、草稿恢复/放弃/保存和章节筛选。原 63 项阅读、36 项触摸和 31 项面板回归仍通过，其中竖排触摸场景启用了界行与版框。
- 图标预览见 `output/playwright/icon-masks.png`；脚本 `scripts/render-icon.mjs` 检查全部非透明前景像素的安全范围。`scripts/verify-release-icons.mjs` 对最终 APK 的 15 份启动图标 PNG 做像素比对，并核对普通/圆形图标的自适应图层引用。

## 0.3.12：手机书架、分类、书签和返回

- 书籍更多菜单统一使用视口内面板，解决左列封面弹出菜单超出屏幕的问题；更多按钮背景透明，仅保留三个点和可点击区域。
- 手机分类栏独占一行横向滑动，统计、备份、同步另起一行；新增未分类入口、分类管理与批量整理。
- 分类管理支持新建、重命名和删除确认；批量整理可搜索书名/作者，按原分类筛选，全选当前结果后移动。失败时保留尚未完成的选中项，成功写入后才移除选择。
- 删除分类将直属书籍移到未分类，子分类提升一级，保留后代分类与书籍；写入分类删除墓碑供同步使用。
- 电子书和 PDF 的「书签」入口打开管理面板，可新增当前位置、查找、跳转、重命名和确认删除；相同位置不重复添加，删除使用已有持久化与同步墓碑机制。
- Android 禁用 Wry 默认历史导航，使用 Activity 返回回调直接调用页面处理器；关闭弹层优先，正常阅读返回书架，书架连续两次才退出。网页后退继续使用同一处理器栈。系统栏、屏幕缺口及键盘空间通过原生窗口内边距避让。
- `npm run test:library` 的 24 项检查覆盖 320/390/460 像素屏幕菜单、透明按钮、分类栏、批量归类、父分类删除、持久化、正文/PDF 书签和返回回调。连同原有回归共 177 项通过。手机真机当前未连接，原生返回手势和系统安全区仍需设备验证。
