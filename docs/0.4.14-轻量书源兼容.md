# 0.4.14 第一批书源兼容

支持匿名 GET/POST、普通请求头、GBK 常用汉字编码、CSS 链/索引/组合/正则、JSONPath、原生 XPath，以及声明式目录和正文分页。

不支持登录、认证请求头、任意 JavaScript/Java、WebView 交互。GB18030 的四字节扩展字符暂不编码。JSONPath 禁用脚本求值；正则超时会终止处理。

11522 条文件可识别 5449 条，排除登录或认证类 1518 条；762 条旧书源可识别 664 条；1199 条文件可识别 859 条。

“匿名可识别_待联网”文件仅通过规则校验，尚未逐站联网验证，不能据此认定网站有效。旧站点失效、验证码和改版都可能导致搜索失败。

原始 11522 条文件第 9293 条落霞书源已在本机实际网络验证：《西游记》100 章、《红楼梦》120 章，分别搜索并选择前两章入架，均得到两章。该结果不代表安卓实机网络环境。
