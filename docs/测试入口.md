# 测试入口

## 日常检查

安装依赖后依次运行：

```text
npm run version:check
npm run typecheck
npm run test:unit
npm run build
npm run test:smoke
```

冒烟集包括阅读器、面板、触摸选区、跨书检索与回收站。使用隔离浏览器配置，不读取用户日常书库，不连接真实 WebDAV 账号。默认使用 Windows Microsoft Edge；可通过 PW_CHANNEL 指定已安装的浏览器通道。

0.3.19 增加 test-reader-fixes 专项：使用脚本生成的 PDF，不依赖本机书籍，核验 TTS 暂停恢复、备份凭据隔离、PDF 文本层/计时/键盘/批注、菜单留白和剪贴板。

## 发现与专项运行

`npm run test:list` 列出全部脚本，`node scripts/test-runner.mjs all` 依次执行。all 排除 runner 自身；并非全部专项测试都可离线运行：网络书库需要网络/代理，部分历史脚本依赖本机样本文件或原生构建环境，应先查看脚本开头的前提。不能把某个环境不具备的专项测试跳过后称为全量通过。

- 选区与翻页：test-reader、test-selection-touch、test-reading-polish。
- 版式与朗读：test-reading-comfort、test-tts-anchor。
- 书架与笔记：test-library-management、test-large-library、test-shelf-home、test-notes-manager。
- 搜索与恢复：test-search-recycle。
- 网络书库：test-network-formats、test-public-libraries、test-wiki-directory、test-haodoo。
- 安装产物：verify-release-assets、verify-release-icons。

上述名字对应 scripts 下的 .mjs 文件，使用 `node scripts/名称.mjs` 单独运行。截图统一保存在 output/playwright；失败时优先保留终端输出与截图定位原因。

## 实机验收

浏览器回归不能代替安卓 WebView 的触摸、锁屏朗读、系统分享、文件导出权限和真实多设备同步验收。签名 APK 和 Windows 安装包须验证内嵌资源，不能仅按文件名认定是最新源码。
