# 阅读树 0.3.15

版本号 0.3.15，Android versionCode 3015，沿用原应用标识与签名。

新增六个按需接入的书库：中文维基文库、中华诗词、Kanripo 汉籍、中国哲学书电子化计划、GITenberg、Standard Ebooks。无需大型依赖，不预下载书籍或整个 GitHub 仓库。

- 维基文库：经典起始目录；可粘贴作品页面地址，选择篇章入架。保留来源，版权与版本以原站为准。
  增补典籍门户分层目录，按原站 21 个非空栏目浏览作品；每页最多 50 项。分类通过 MediaWiki categorymembers 接口继续翻页，支持子分类与子门户，返回上层后保留目录路径。十本常读经典仅为快捷入口，并非全部藏书。
- 中华诗词：浏览选集目录，将有正文的 JSON 文件整理为含题目、作者、诗句的 HTML 选集。
- Kanripo：分页浏览汉籍仓库；选卷入架，移除技术属性、页码标记，保留原文与篇章标题。
- 中国哲学书：公开目录与所选篇章；部分正文要求浏览器验证，提供原站入口，不绕过验证。
- GITenberg：分页书目与仓库文件浏览，不导入仓库配置与元数据。
- Standard Ebooks：公开网页书目与兼容 EPUB 下载；未采用需要授权的 OPDS 接口。

书格、古腾堡澳大利亚、Faded Page、古腾堡加拿大、Internet Archive 作为外部网站入口。影印 PDF 常有数十至数百 MB；书库链接几乎不增加安装体积，下载文件单独占存储。应用单文件下载限 256 MiB，超限文件请在原站下载后本地导入。

文字篇章一次最多 10000 篇、合计正文/原始响应最多 256 MiB。默认仍选 20 章，可以手动输入 5000 或 10000；按实际目录余量下载，逐章请求、显示进度并允许取消。取消时不生成部分书籍。合并正文占用运行内存，大量章节建议分批；GitHub 匿名接口有频率限制，维基文库等站点可能限制访问；部分网络在安卓上需要可用代理，电脑代理不会自动配置到手机。

夜间暖色修正为阅读区域上的轻微暖色覆盖，最高不透明度 18%，设置面板不着色。

书籍管理菜单新增「标记已读完 / 标记未读完」，状态重启后保留，纳入已读完筛选与藏书树成熟状态，随元数据备份与同步；不改变真实阅读位置、正文或笔记。标记已读完后不再出现在首页续读推荐。

本次设备成功入架的网络章节会保存下载记录：重复选择时跳过仍在书架中的章节，再次进入目录默认从第一篇未下载章节开始。删除对应书籍后可以重新下载。升级前已下载章节没有历史记录，无法可靠追溯；中途取消的批次不保存部分正文，不提供字节级断点续传。下载记录暂为本机记录，不跨设备同步。

验证使用真实网站响应、移动宽度界面与现有导入阅读回归。未连接安卓实机；设备安装与现场网络仍需用户验证。

交付：签名 Android APK 约 32.12 MiB，Windows x64 安装包约 4.54 MiB，与上版体积接近。已核验版本 0.3.15 / 3015、原签名、两个安卓架构及 Windows 内嵌资源与最终代码一致。Windows 实际程序通过系统网络下载维基文库篇章；关闭托盘、恢复和真正退出均通过。源码不包含签名密钥、私人书籍和构建缓存。
