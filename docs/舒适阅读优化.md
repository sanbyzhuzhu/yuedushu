# 舒适阅读与好读书库（0.3.14）

开发者：如水书斋 · 朱振坚。版本号与 Android versionCode 保持 0.3.14 / 3014。

## 阅读排版

- 原书固定像素字号按正文基准转为阅读字号的比例。标题、加粗、斜体、居中可保留；字体、行距、纸墨与页边距由用户设置控制。
- 修改发生在显示层，已导入的书无需重新导入，章节正文与笔记引用不改写。
- 设置“更多 → 原书排版”可即时切换保留样式或统一排版。以统一排版导入的旧书无法凭空恢复已去除的原书样式。
- 脚注标记图片保持一行内，普通插图保持比例并限制在阅读区域，滚动模式同样有效。点击插图仍可看大图。
- “常用 → 页面留白”增加紧凑、舒适、宽松预设；“版式”可独立调整。页眉页脚开启时保留必要距离，小屏限制过大边距，横排版框增加内留白并遮住邻页外溢。
- 图片解码完成后重新计算页数，保留当前页。

## 支持格式

EPUB、TXT、Markdown（MD / MARKDOWN）、DOCX、PDF、MOBI、AZW / AZW3、PRC、FB2 / FB2.ZIP、CBZ、UPDB、OFD、ODT、HTML / HTM / XHTML。

支持未加密书籍，不支持旧 DOC；ZIP 仅 FB2.ZIP。PDF 支持原版阅读及文字层重排；OFD 支持文字、PNG/JPEG 图片重排，不含 OCR、签章与矢量图。

## 好读

- haodoo.net：应用内分类、书目、详情及公开 EPUB 下载入架。只识别已核验下载函数的固定参数，不运行远程 JavaScript。
- haodoo.org：应用内浏览公开书目与下载详情，可在系统浏览器打开当前页。需登录或购物车的下载在原站完成，再从本地导入。
- Windows 原生网络组件支持系统代理；无需把本机代理端口写入应用。Android 需设备自身网络可达（电脑代理不会自动共享到手机）。
- 仅按需加载页面与选定文件，没有预装书库、代理内核或浏览器引擎，没有新增依赖。

## 验证

`scripts/test-reading-comfort.mjs [EPUB 路径]` 包含固定字号、脚注图、长图、横竖排点击、滚动排版、原有笔记保留；可传入私人 EPUB 在隔离书库复现，书籍不打入源码。

已使用用户提供的《巴拉吉预言：技术、真相和构建未来的指南》“关于本书的重要说明”实测：设置 19 / 28 / 36，正文实际字号对应 19 / 28 / 36。
同一本书的 28 张插图在 390px 手机视口中均完成解码，显示宽高限制在阅读区域内。

`scripts/test-haodoo.mjs` 检查分类、下载端点、分页、脚本白名单及不触发购物车；如有本地保存的真实响应，会额外验证真实网站书目。
