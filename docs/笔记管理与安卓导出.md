# 笔记管理与安卓导出（0.3.15）

书架 → 更多 → 笔记管理，可独立阅读全部书籍的划线与批注。可按书筛选、搜索原文与批注、只看有批注的记录，每页显示 50 条；支持编辑批注、确认删除、导出筛选结果为 Markdown。书签仍在各书的书签管理中。

安卓 10 及以上：笔记 Markdown、TXT、CSV 与分享图片默认保存至系统 `Download/阅读树`，通过 MediaStore 写入，实际完成后显示位置，不要求所有文件访问权限。同名文件由系统保留为不同文件。安卓 7–9：通过系统“保存文件”窗口选择位置，不要求存储权限。网页版与 Windows 当前仍使用浏览器下载机制，其下载位置由浏览器设置决定。

补充旧版 Android System WebView 缺少 `AbortSignal.throwIfAborted` 时的兼容处理，避免网络书库、章节下载、重排与备份在取消检查处抛出 TypeError。安卓原有 HTTP 请求失败时，使用系统 HTTPS 通道重试，遵循系统证书与代理设置；保留 HTTPS、逐次跳转的凭据隔离、下载大小限制及取消操作。安装版网络错误不再误提示网页跨域问题。此兼容修复不能解决设备本身无法访问外网、站点封锁、需要代理或证书问题。

关于阅读树新增简介，介绍离线藏书、繁简与横竖排、独立版式、自定义字体、万本书架、网络书库与 WebDAV 同步。版本仍为 0.3.15。
