# 阅读树 0.3.14 打包与交付

2026-10-07 舒适阅读更新见文末与 [舒适阅读优化](舒适阅读优化.md)。旧清简书架安装包另存于 `releases/0.3.14/清简书架版_旧包/`。

## 交付文件

所有产物位于 `releases/0.3.14/`：

- `阅读树_0.3.14_Windows_x64_安装版.exe`：Windows 64 位 NSIS 安装程序。
- `阅读树_0.3.14_Android_release.apk`：Android release 签名安装包，包含 arm64-v8a 与 armeabi-v7a，最低 Android 7.0。
- `阅读树_0.3.14_源码.zip`：本次修改后的源码、锁文件、原生工程和测试脚本。
- `SHA256SUMS.txt`：文件完整性校验。

版本号保持 package.json、npm 锁文件、Cargo 工程和 Tauri 配置一致。应用标识和 Android 签名沿用已有项目，以便在相同签名的旧 release 版上升级。安装前可在旧版应用中导出完整备份。

## 构建环境

- Node.js 20+、npm；先运行 `npm ci`。
- Windows：Rust stable MSVC、Visual Studio C++ 构建工具、Windows SDK；应用运行需要 WebView2。
- Android：JDK 21、Android SDK（compileSdk 36）、NDK 27.1.12297006，以及 `aarch64-linux-android`、`armv7-linux-androideabi` Rust targets。
- 脚本使用 `JAVA_HOME`、`ANDROID_HOME` 和有效的 `NDK_HOME`，失效的旧 NDK 路径会回退到 SDK 内的 27.1.12297006。优先复用项目 `.gradle-home` 缓存，可用 `RELEASE_GRADLE_HOME` 指定其他目录；无项目缓存时采用 `GRADLE_USER_HOME`。本机 Node 路径有冲突时可设置 `RELEASE_NODE_HOME`。

## 签名

源码压缩包不包含签名密钥与密码。原签名文件仍保存在项目本地；发布升级版本必须继续使用相同密钥。

正式 Android 构建支持三项环境变量：

```text
TAURI_ANDROID_KEYSTORE_PATH
TAURI_ANDROID_KEYSTORE_PASSWORD
TAURI_ANDROID_KEY_ALIAS
```

也可在项目根目录使用不加入版本控制、不进入源码归档的 `.android-signing.local.json`：

```json
{
  "keystore": "签名文件的相对或绝对路径",
  "password": "你的签名密码",
  "alias": "你的签名别名"
}
```

仅需调试时运行 `node scripts/release.mjs android debug`，其应用标识有 `.debug` 后缀，与正式版分别安装。

## 命令

```sh
node scripts/release.mjs windows
node scripts/release.mjs android
node scripts/release.mjs source
# 依次构建两端，归档当前源码并生成校验文件
node scripts/release.mjs all
```

不要同时执行两端构建，它们共享前端产物目录。发布文件位于独立 releases 目录，不会被下一次前端构建清空。

旧脚本使用 `git archive HEAD`，会漏掉未提交的优化。现脚本以 Git 文件清单为基础读取当前工作内容，并包含未忽略的新文件；没有 Git 的解压源码也可重新归档。打包后校对关键源码字节，排除密钥、本地配置、依赖与缓存。

## 确认安装了新版

安卓请使用本目录的 0.3.14 release APK 覆盖安装，打开书架，点击右上角「⋯ → 关于阅读树」，应显示「v0.3.14 · 清简书架版」。旧的前选/后选 80 字按钮已删除。若看不到新标记，请核对是否打开了旧应用或另装的 debug 版，不要先卸载或清除书库数据。

使用：长按文字，拖动两端圆点精确选字。横排到本页末行后继续向下拖才翻一页；竖排到末列末尾后继续拖才翻一页。停住不会连翻，翻后回到正文继续选字才可再次翻页，也可反向返回缩选。单条笔记仍限同一章。

`node scripts/verify-release-assets.mjs` 会逐字节比对两种 Android 架构实际 APK 内嵌的压缩前端与当前生产包，并检查 Windows 可执行文件嵌入了同一前端，防止只改源码却装入旧页面。

图标修改后运行 `node scripts/render-icon.mjs`，统一生成桌面和安卓资源，再构建安装包。完成 Android 构建后运行 `node scripts/verify-release-icons.mjs`，核对最终 APK 的 15 份 PNG 像素、版式和背景引用。仅运行 `tauri icon` 会覆盖自适应前景，请使用项目脚本完成安全留白处理。

## 继承的阅读细节

竖排启用版框时，正文顶部和底部增加约 0.6 个字的留白；关闭版框恢复原排版高度。新图标针对 Android 圆形及圆角图标做了安全边距，保留五色果实和书本。目录面板顶部可按章节名筛选。

笔记编辑中，未正式保存的文字自动暂存在当前设备；关闭编辑页或重开应用后再点同一划线，可继续写。点击「保存笔记」才成为正式笔记并进入备份、导出和同步；「放弃草稿」恢复原笔记。草稿不跨设备同步，清除应用数据会一并清除。

## 继承的书架与书签管理

手机点封面上的透明三个点，在完整面板中编辑信息或移入分类。书架「分类管理」可新建、重命名、删除分类；「批量整理」可搜索、按分类筛选、全选当前结果后移入分类。删除分类仅将其直属书籍移入未分类，子分类提升一级，不删除书。

阅读菜单中的「书签」打开管理页，可添加当前位置、改名、查找、跳转、删除，PDF 同样支持。Android 返回键直接交给页面处理，不再依赖 WebView 是否存在历史；弹层优先关闭，正常阅读返回书架，书架连续两次返回退出。已完成浏览器原生回调入口检查及 Android Kotlin release 编译，仍需真机确认系统返回手势、键盘和安全区表现。
