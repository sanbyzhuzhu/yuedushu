# 0.3.20 右侧选字修复

横排分页器的右侧 padding 包含阅读边距与额外 column gap；后者保证末页能够完整滚动定位。选区控制器此前直接扣除整个 paddingRight，导致右侧可选范围缩短一个 gap，底纹和拖动命中同时被裁剪。

现在横排分页以 page-inner 的实际排版宽度确定选字区域，滚动阅读仍按原有边距计算，竖排仍使用 page-clip。额外考虑预览缩放后的坐标比例。翻页意图判断规则未调整。

验证：TypeScript 检查通过；右边缘专项脚本模拟 40px 尾部分页间隔，确认旧边界漏掉多行末字，新边界覆盖全部选中文字且逐行能命中末字；36 项触屏与 63 项阅读回归全部通过。

验证环境为桌面 Chromium 的触屏模拟，尚未在用户安卓真机上复测。
