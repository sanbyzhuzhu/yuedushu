# 0.4.8 应用内更新、封面与隐藏书架

## 更新方式

此前版本只有确认后打开浏览器下载。0.4.8 增加应用内下载，仍不自动下载、安装或弹窗提醒。

1. 更多 → 检查更新，发现新版本后点击“应用内下载”，确认开始。
2. 下载中显示进度，可取消，也可关闭面板继续阅读。
3. 下载完成后点击“安装更新”，再次确认后才开始安装。
4. Windows 采用官方 Tauri updater，配置 quiet 模式；验证签名、签署版本及较新版本后，退出应用并覆盖安装、重新打开。系统权限提示由系统决定。下载失败、签名不匹配、版本变化都不会执行安装。
5. 安卓通过 DownloadManager 后台下载。下载状态可在重启应用后继续读取；下载完成时先复制到应用内部缓存，校验 SHA-256、包名、版本名及签名一致性，再允许打开系统安装界面。首次可能需要授权“允许此来源安装应用”，授权返回后再点击安装。普通安卓应用不绕过系统安装确认。

浏览器下载入口继续保留。没有签名或校验信息的旧更新清单仍可使用浏览器下载。

首次需手动安装 0.4.8，之后才能使用新增的应用内更新功能。Windows 下载保留在当前应用会话中；退出应用后需重新下载。安卓系统下载任务可跨应用重启继续。

## 封面

保存按钮会等待封面处理完成，封面与书籍信息一起写入本地。封面单独记录修订时间；较旧的云端封面不会覆盖新封面，主动清除封面也不会被补回。同步过程中的旧元数据写回会检查版本，保留刚保存的本地修改。

## 隐藏分组

- 书籍菜单 → 移入隐藏分组。
- 编辑信息中可勾选“移入隐藏分组”。
- 批量归类的目标分类可选择“隐藏”。
- 电脑侧边栏或手机“全部分类 → 隐藏”中查看；隐藏书仍支持正常阅读。
- 隐藏后不在首页、普通分类、首页搜索和继续阅读中展示；移出隐藏分组恢复原分类。移动到某个普通分类也会取消隐藏。
- 隐藏是书架整理方式，不是加密或访问密码；书籍仍在本地，完整备份、同步、笔记等功能会保留它们。

## 发布维护

保管本地 `.updater-signing.local.json`，不要上传、放入源码包或与安装包分发。该文件丢失将无法为已安装客户端签署可信更新，不能用新密钥替换现有更新通道。

`scripts/release.mjs all` 在构建两端后对 Windows 安装包签名，并将签名及两个安装包的 SHA-256 写入 `update.json`。先上传且验证安装包，再更新仓库公开清单。两个源码仓库和清单都无需保存私钥。

## 回归入口

- `scripts/test-cover-hidden.mjs`：封面保存/重启、旧写入保护、隐藏/恢复、各视图与首页排除。
- `tests/coverMerge.test.ts`、`tests/syncMultiAccount.test.ts`：封面合并、明确清除及同步中用户编辑保护。
- `scripts/test-in-app-update.mjs`：模拟原生桥接验证下载进度、取消、关页继续、安装前再次确认与签名失败阻止安装，不执行安装程序。
- `scripts/verify-update-signature.mjs`：正式 Windows 安装包及可信版本签名、篡改拒绝、双端清单校验值验证。

自动化不会实际替换当前电脑安装的应用，安卓系统安装确认仍需真机使用验证。
